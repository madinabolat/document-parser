# document-parser
A file parser. 

## Input:
- PDF file
- Schema. 

## Result: 
- Renderer 
- Rationale 
- Bounding box 

## UI: 
- Upload a pdf
- Provide a Schema (Ex. Policy Number)
- Returns the extracted value
- Returns the rationale (explanation)
- Renders pdf with highlighted location in the source file 

## Stack: 
next.js, node.js, vercel
